# CAPABILITIES — verified graph8 surface for Conductor

Verified 2026-09-26 against `@graph8/sdk@0.245.0` (`node_modules/@graph8/sdk/dist/index.d.ts`, "idx:N" = line)
and the live graph8 MCP tool list (org **Hackathon Umair Abbas**, `org_05cbf5680891`).
Only names listed here may be used in code. Anything marked **NOT FOUND** must not be called.

SDK conventions:
- `g8.init({ apiKey })`. The default `apiUrl` is `https://be.graph8.com`, with base path `/api/v1`.
- Generated calls take the form `g8.api.<tag>.<op>({ path?, query?, body? }, { idempotencyKey? })` and return `{ data, pagination? }`. There are 3,247 operations.
- Errors throw `G8Error { status, type, code?, requestId?, retryable }` (idx:2861).
- 429 and 5xx responses are retried automatically.
- Writes get an `Idempotency-Key` automatically, or we pass our own with `idempotencyKey` (idx:2904).

## Implications / decisions for later phases
1. **Enforcement = reactive.** Conductor uses `pauseSequenceContact` (per sequence) or `withdrawContactsFromSequences`. Suppression is reserved for R4 budget holds, if we choose to use it at all.
2. **Real-time transport.** graph8 webhooks need a public URL, and this machine is local. Without a tunnel (which needs approval), we poll `listOrgEvents({since})` and `getContactSequences` every 5s. `/api/webhooks/graph8` still exists, with signature verification.
3. **Seeded history.** The API has no way to log a past SMS, LinkedIn, dialer or newsletter touch, and we must not really send to fake people. The seed therefore creates **real** CRM records in graph8 (companies, contacts, deals owned by Ali, a draft sequence that is never run, custom fields, and the `conductor-demo` list tag). Sarah's historical touches, including her meeting booking, live in `seed/scenario.ts`, with times relative to today. They are mapped onto the real graph8 ids through `data/seed-state.json`. Live graph8 events merge on top.
   - We do not create a graph8 meeting record. `createCrmMeeting` requires an external CRM `connection_id`, and `appointments.createBooking` emails the attendees.
4. **Custom fields are text only.** We parse them on read.
5. **Owners.** "Ali" (AE) and "Bilal" (SDR) must be real team members for tasks and deal ownership to work. If the org has only one member, we map both to that member and keep the display names in the seed.
